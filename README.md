### ☁️ 1. Cloud Platform — AWS

\<p>\
&#x20; \<img src="[https://img.shields.io/badge/Amazon_AWS-FF9900?style=for-the-badge&logo=amazonaws&logoColor=white](https://img.shields.io/badge/Amazon_AWS-FF9900?style=for-the-badge\&logo=amazonaws\&logoColor=white)" alt="AWS"/>\

**Services I study and practice:**

- **EC2:** Launch and manage virtual servers.
- **S3:** Store files, application assets, and backups.
- **IAM:** Manage users, roles, and permissions.
- **VPC:** Create isolated cloud networks and subnets.
- **RDS:** Work with managed relational databases.
- **Lambda:** Run code without managing servers.
- **CloudWatch:** Monitor metrics, logs, and alarms.
- **Elastic Load Balancing:** Distribute incoming traffic.
- **Auto Scaling:** Adjust computing capacity based on demand.

## 🚀 Projects & Hands-On Learning

I focus on practical projects that help me understand how cloud infrastructure and software delivery work together.

### ☁️ Project 1 — AWS Three-Tier Web Architecture

**Objective:** Understand how a web application can be hosted securely and reliably on AWS.

**Key components:**

- VPC with public and private subnets.
- EC2 instances for application hosting.
- Application Load Balancer for traffic distribution.
- RDS for relational database storage.
- IAM and security groups for access control.
- CloudWatch for monitoring.

**Skills demonstrated:** Networking, compute, security, database integration, and cloud architecture.

### 🔄 Project 2 — Automated CI/CD Pipeline

**Objective:** Automate the process of delivering application updates.

**Workflow:**

`Code → GitHub → Jenkins → Build → Test → Deploy`

**Key learning areas:**

- Source-code version control.
- Automated builds and tests.
- Deployment workflows.
- Environment configuration.
- Build and deployment troubleshooting.

### 🐳 Project 3 — Docker & Kubernetes Deployment

**Objective:** Package an application into a container and learn to deploy it with Kubernetes.

**Key learning areas:**

- Writing a Dockerfile.
- Building and running container images.
- Managing Kubernetes Deployments and Services.
- Configuring application replicas.
- Understanding application scaling and recovery.

### 🏗️ Project 4 — AWS Infrastructure with Terraform

**Objective:** Provision cloud resources through reusable configuration files.

**Key learning areas:**

- Terraform providers and resources.
- Variables and outputs.
- State management fundamentals.
- Infrastructure planning and deployment.
- Resource cleanup and cost awareness.

### 📊 Project 5 — Monitoring with Prometheus & Grafana

**Objective:** Learn how to observe application and infrastructure performance.

**Key learning areas:**

- Collecting metrics.
- Building monitoring dashboards.
- Setting alert conditions.
- Investigating resource usage and service health.
